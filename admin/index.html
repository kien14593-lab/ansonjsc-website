Thiết lập đăng nhập

Chỉ làm một lần. Sau bước này, người được cấp mật khẩu có thể đăng nhập bằng tên đăng nhập + mật khẩu từ bất kỳ máy nào.

1 Mã truy cập GitHub (token)

Cách tạo token (khoảng 1 phút)
  1. Đăng nhập GitHub bằng tài khoản , rồi mở github.com/settings/personal-access-tokens/new.
  2. Token name: Quan tri website. Expiration: chọn Custom và đặt ngày xa nhất được phép (tối đa 1 năm; khi hết hạn chỉ cần thiết lập lại).
  3. Repository access → Only select repositories → chọn .
  4. Permissions → Repository permissions → Contents: Read and write (Metadata tự bật ở mức Read).
  5. Bấm Generate token, sao chép chuỗi github_pat_… và dán vào ô dưới.

2 Tên đăng nhập và mật khẩu

Hãy lưu mật khẩu này lại ngay. Mật khẩu không được lưu ở bất kỳ đâu và không thể khôi phục – nếu quên, chỉ có thể thiết lập lại bằng token GitHub mới. Ai biết mật khẩu đều có thể đăng bài, sửa bài.
